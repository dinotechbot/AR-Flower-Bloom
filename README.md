# 🌸 AR Flower Bloom

An interactive computer vision project built with Python, OpenCV, and MediaPipe.

The project uses hand gestures and face tracking to create an augmented-reality experience where a colorful flower bouquet appears on the screen and responds to the user's movements.

## ✨ Features

- 🌸 Interactive bouquet of 5 flowers
- 🌺 Flowers bloom as the palm opens
- 🖐️ Real-time hand tracking using MediaPipe
- 💡 Left-hand finger sliding controls screen brightness
- 🕷️ Spider-Man face mask using face tracking
- 🎭 Black & white background effect
- 🎨 Flowers and face mask remain colored when the background filter is enabled
- 📷 Real-time webcam interaction
- 🖥️ Large/resizable camera window

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Math
